# 图片提示词：十层模板详解

目标：一张"精致但真实"的超写实人物首帧图。提示词按十层从上到下组装，
每层一段自然语言（不是关键词堆砌），总长度 300–800 字为宜。

## 可复制骨架

```text
【1 风格定调】<超写实|日系胶片|电影肖像>，<质感关键词：RAW 照片 / 胶片颗粒 / 4K>，
<整体氛围一句话>。

【2 构图机位】<景别：极端脸部特写|特写半身|中近景>，<画幅：9:16 竖构图>，
<机位：平视|微俯>，<角度：正面|3/4 侧>，<裁切许可：允许额头被裁切，
甚至只展示眼睛鼻子嘴唇>，<构图气质：像高级随手抓拍|符合黄金比例>。

【3 人物基础】一位 <年龄> 岁的 <族裔> <性别>，<体态骨相>，
<气质定位：日系清新|沉着威严|清纯>。

【4 发型头饰】<发型结构>；<碎发/鬓发细节>；<饰品逐件：材质+颜色+位置+垂坠>。

【5 服装配饰】<形制与层次>，主色调 <颜色名>（#HEX），<面料材质与光泽>，
<工艺细节：刺绣纹样|纽扣|项圈|耳饰>。

【6 五官锚点】<眉形>；<眼型（含排除：丹凤眼而不是大圆眼）>；<双眼皮宽窄>；
<虹膜颜色与神采>；<鼻梁鼻头>；<唇形唇态>；<脸型与下颌线>。

【7 妆容】<底妆厚薄通透度>；<眼影色系与晕染>；<眼线>；<睫毛>；
<腮红位置>；<唇色与质地（哑光|光泽）>。

【8 皮肤真实感——最高优先级】真实的摄影皮肤纹理，鼻部和脸颊清晰可见细微毛孔，
自然汗毛/毳毛在<光线条件>下隐约可见，额头和鼻梁有自然镜面高光，
<肤色基调>，可有极淡雀斑或少量细微瑕疵；保留轻微自然不对称：
两侧眼睛大小开合有极轻微差异，嘴角有极细微不对称，眉毛高低带自然差别；
非磨皮，非塑料感，非 AI 平滑，不要蜡像感，必须是真实人类皮肤质感。

【9 光线】<主光：右侧柔和侧逆光|明亮自然光|高级棚拍光>，<色温：暖金色调>，
<轮廓光：勾勒脸部边缘和头发>，<补光：柔和正面补光避免死黑>，
光线必须充足通透、有明暗层次，能看清毛孔与绒毛。

【10 背景+质量词】背景<完全虚化的散景描述>（#HEX），<隐约可见的环境元素>，
景深较浅，焦点精准落在<眼部>。超写实 4K 电影肖像，超高细节，
细微胶片颗粒，栩栩如生。
```

## 每层要点

### 1. 风格定调
第一句话决定整体走向。有效组合：
- 现代写实：`超写实、日系艺术摄影质感` / `日系胶片电影写真，低饱和色调，RAW照片`
- 古装剧感：`超写实4K电影肖像，丰富的电影级色彩分级`
质量词（最佳品质、杰作、超级细致）放在这里或第 10 层，不要满篇撒。

### 2. 构图机位
- **裁切许可**是特写出片率的关键："不需要完整展示整张脸，允许额头部分被裁切，
  甚至只展示眼睛、鼻子、嘴唇和部分脸颊区域"——给模型自由度反而更自然。
- 半身像写清身体角度与头部朝向的差异（"身体呈 3/4 角度略微向左，头部朝向前方"），
  这决定了后续视频里"转头看镜头"的表演空间。**如果视频要演"发现来人再转头"，
  首帧就该让头和视线朝向侧面。**

### 3. 人物基础
"人设锚"比形容词有效："28 岁的东亚贵族女性，散发沉着威严和沉静智慧的气息"
胜过"漂亮有气质的女人"。年龄要具体到数字。

### 4–5. 发型/服装
- 逐件描述，每件 = 材质 + 颜色 + 结构 + 位置。颜色关键处给 hex 值
  （如 `暖琥珀橙色（#F2A13D）`），跨次生成时颜色可复现。
- 饰品的"物理关系"要写（"垂过下颌线""华丽地佩戴在胸前"），帮助模型建立空间结构。

### 6. 五官锚点
这一层是后续视频防"变脸"的基准，必须逐项、可判定：
- 眉：形状 + 走势（"纤细柳叶眉，眉梢锐利上挑"）
- 眼：**用排除法钉死眼型**（"经典丹凤眼，而不是大圆眼，外眼角略微上扬"）
- 双眼皮：宽窄与平行/开扇
- 虹膜：颜色 + 神采（"深棕色近乎黑色，明亮而富有洞察力"）
- 鼻/唇/脸型：逐项一句

### 7. 妆容
妆容独立成段，与皮肤层分开。写清"妆感厚度"（轻薄通透 / 浓郁哑光），
它直接影响皮肤纹理的可见度。

### 8. 皮肤真实感（不可省略、不可删减）
固定三件套：
1. **正向纹理**：毛孔（点名部位：鼻部和脸颊）、汗毛/毳毛（点名光线条件下可见）、
   自然高光（额头、鼻梁）、微瑕疵/淡雀斑。
2. **轻微不对称**：眼、嘴角、眉毛的极细微差异——"整体仍然精致和谐，不要做成明显变形"。
3. **反磨皮否定串**：非磨皮、非塑料感、非 AI 平滑、不要蜡像感、不要 CGI 皮肤。
   可加一句定性："是'美女的真实皮肤'，绝不是粗糙问题肌，也不是过度磨皮的假脸。"

### 9. 光线
光线的任务是"让皮肤细节可见"：明确写"让皮肤纹理、毛孔、绒毛都能被看清"。
侧逆光 + 轮廓光 + 正面补光是安全组合；情绪题材可加定向细节
（哭戏："让泪光、鼻头微红和眼部微红都能被看清"）。

### 10. 背景 + 质量词
背景必须虚化并给基调色 hex；可写"隐约可见"的环境元素增加叙事感
（彩绘屏风轮廓 / 朦胧树叶剪影）。收尾质量词固定：
`超写实 4K，超高细节，浅景深，细微胶片颗粒`。

## 情绪状态图（可选加层）

如果首帧本身要带情绪（如"哭过的脸"），在第 3 层和第 8 层之间插入情绪层，
写法遵循"轻微、真实、克制"：
- 写生理痕迹而非表情符号："鼻头自然微微发红；眼角、下眼睑和眼眶边缘略微发红，
  带一点点血丝和湿润感，可以有非常轻微的泪光"
- 立刻跟排除："不要夸张，不要狼狈，不要双颊大面积泛红"
