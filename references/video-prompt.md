# 视频提示词：八段模板详解

目标：以首帧图为锚，生成 4–6 秒"真人感情绪表演"视频。提示词按八段组装，
总长度 400–1200 字。段落越靠前越是"硬约束"，越靠后越是"表演指导"。

## 可复制骨架

```text
【1 画面配置】竖屏 9:16，写实真人感情绪表情视频，以当前图片作为首帧生成视频。
<机位：自然晃动的手持机位|固定机位>，中近景半身构图。镜头整体保持稳定，
<机位气质：像古装剧现场实拍的手持摄影，带非常轻微的呼吸感和自然微抖>，
人物始终稳定居中，面部清晰锐利。

【2 首帧一致性锚定】面部特征必须严格保持一致，并在<转头|看向镜头|情绪变重>时
依然稳定不变：<把图片提示词第 6 层五官锚点原样重申，含排除法：
经典丹凤眼而不是大圆眼>。不要出现<幼态圆眼|脸部变宽变短|鼻型变钝|嘴唇变薄>。
```

## 每段要点

### 1. 画面配置
- 固定开头：`竖屏 9:16，写实真人感情绪表情视频`；图生视频必须写明
  `以当前图片作为首帧生成视频`。
- 机位二选一：**手持微晃**（生活感/剧感强，写"带有非常轻微的呼吸感和自然微抖，
  但人物始终稳定居中"）或**固定机位**（表情特写更稳）。
- 禁止运镜：`不要切镜头，不要明显运镜`——运镜是首帧漂移的头号诱因。

### 2. 首帧一致性锚定（防变脸核心）
- 把图片提示词的五官锚点**原样重申**，尤其排除法（"丹凤眼而不是大圆眼"）。
- 预判漂移方向并点名禁止："无论头部角度如何变化，都不要把她变成圆眼"
  "不要幼态圆眼、脸部变宽变短、鼻型变钝、嘴唇变薄"。
- 情绪越强、转动越大，这段越要写足。经验规律：**转正脸的一瞬间最容易漂移**。

### 3. 皮肤质感重申
图片第 8 层的压缩版，三句以内：毛孔 + 汗毛 + 反磨皮否定。

### 4. 人设 + 声音
- 人设用**排除法**塑形："她不是少女式撒娇，不是软萌卖甜。她是 32 岁左右、
  明艳、精明、很会应酬的成熟贵妇。"排除项就是模型最容易跑偏的方向。
- 有台词必写声音段：年龄音色 + 质感形容 + 禁止项（夹子音/少女音/哭腔）。

### 5. 情绪设定 + 强度分
- 用"不是…而是…"写情绪的内在逻辑："不是崩溃，不是愤怒大喊，
  而是眼里的光暗下去，心里彻底落空。"
- **强度分是防过火的关键**：日常情绪 4–6 分，重情绪 8 分，夸张戏剧 9 分。
  不写分数时模型倾向演过头。

### 6. 分秒拆解（表演的灵魂）
- 粒度 0.5–1.5 秒一段；总时长 4–6 秒（对应 duration 参数）。
- 只写**镜头可见的物理变化**：眼皮开合、嘴角弧度、鼻翼、呼吸起伏、肩膀、
  下巴、头颈角度、手部小动作。心理描写必须落到物理表现上。
- **因果链**：每一拍由上一拍触发。标准链条：
  `察觉 → 眼神先动 → 表情变化 → 头部转动 → 肩颈/上半身跟随`。
  反例是凭空转头、无动机微笑。
- 复杂情绪用"纠结结构"：看过去 → 认出来 → 不想看转开 → 忍不住转回 →
  发狠盯住 → 说话。层次感来自"反复"。
- 憋笑类递进结构：第一次看镜头憋住 → 第二次快憋不住 → 第三次彻底笑出来。
  重复动作 + 每次加码 = 真实感。

### 7. 台词与口型
- 台词单独成段：`口型清楚` 必写；声音质感用三连形容（低、轻、沙 / 清亮、利落、带笑）；
  尾音明确处理（下沉 = 心灰意冷 / 拖长 = 亲昵 / 上扬 = 撒娇）。
- 给台词留时长预算（"时长大约 0.8 秒"），并写"说完之后"的表情残留
  （"嘴角继续翘着，眼睛仍然看着镜头"）——收尾残留决定视频最后一帧的质量。

### 8. 表演要求 + 反向提示词
- 表演要求 = 分秒拆解的逻辑链总结 + 最重要的防漂移重申。
- 固定否定串（每条视频提示词必带）：
  `不要字幕，不要水印，不要夸张表演，不要 AI 僵硬感`
- 按需追加：不要卡通感 / 不要过度美颜 / 不要机械眨眼 / 不要切镜头 /
  不要明显运镜 / 不要猛地扭头 / 不要反复摆头。
- 情绪类否定（按情绪反向排除）："不要哭泣，不要愤怒大喊，不要眼神空洞，
  不要冷漠厌恶，不要夸张嘟嘴，不要卡通撒娇"——把"隔壁情绪"全部关掉。

## "镜头即对象"技巧

单人对镜表演时，把镜头设定为戏剧对象："画面中只有女主一个人。
'来人'就是镜头本身，就是观众。"随后所有眼神调度（看向镜头 = 看向来人、
避开镜头 = 不想理他）都获得了叙事动机，表演立刻有对手感。
